# 木墨文坊系统概述

## 🎯 系统简介

木墨文坊是一个基于React+Antd+Zustand+Vite的现代化AI智能小说创作平台，旨在为作者提供高效、智能的写作体验。平台集成了AI技术，支持智能写作、世界观构建、创作管理等功能。

## 🚀 技术架构

### 前端技术栈
- **框架**: React 18 + TypeScript
- **UI组件库**: Ant Design 5.x
- **状态管理**: Zustand
- **构建工具**: Vite
- **路由管理**: React Router DOM
- **HTTP客户端**: Axios
- **数据可视化**: AntV G6

### 后端技术栈
- **运行环境**: Node.js
- **Web框架**: Express
- **数据库**: MongoDB
- **云服务**: Supabase（可选）

### 核心功能模块
1. **创作中心**: 小说创作、章节管理、大纲规划
2. **AI工作台**: AI辅助写作、内容生成、智能分析
3. **世界观设定**: 角色、地点、文化、科技、魔法、历史六大设定类型
4. **数据同步**: 本地存储与云端同步
5. **用户管理**: 会员体系、权限控制
6. **可视化工具**: 关系图谱、情节结构图

## 🧩 核心功能详解

### 创作中心
创作中心是平台的核心功能模块，提供完整的小说创作环境：
- 小说创建、编辑、删除
- 章节管理与版本控制
- 大纲规划与管理
- 实时字数统计与进度跟踪

### AI工作台
AI工作台集成多种AI模型，提供智能写作辅助：
- 多种AI模型支持（OpenAI、Anthropic、Google、DeepSeek等）
- 智能内容生成（情节发展、角色对话、场景描述等）
- 内容分析与优化建议
- 平行宇宙版本生成

### 世界观设定
世界观设定模块提供完整的六维世界观构建体系：
1. **角色设定**: 完整的角色信息管理
2. **地点设定**: 详细的地点信息管理
3. **文化设定**: 丰富的文化背景构建
4. **科技设定**: 合理的科技体系构建
5. **魔法设定**: 完整的魔法体系构建
6. **历史设定**: 完整的历史脉络构建

### 数据同步
平台支持多种数据存储和同步机制：
- 本地IndexedDB存储
- Supabase云端同步（可选）
- 数据冲突检测与处理
- 批量同步优化

### 用户管理
完善的用户管理系统：
- 用户注册、登录、权限控制
- 三级会员体系（免费、基础、专业）
- AI使用次数统计与限制
- 团队协作功能

### 可视化工具
直观的数据可视化功能：
- 角色关系图谱
- 世界观可视化
- 情节结构图
- 创作进度分析

## 🔄 数据流与同步机制

### 数据流向
1. **AI生成**: AI模型生成内容
2. **智能解析**: 系统自动解析AI生成内容
3. **字段映射**: 将内容映射到对应字段
4. **数据存储**: 保存到本地或云端数据库
5. **界面更新**: 实时更新界面显示

### 同步策略
- **本地优先**: 优先使用本地IndexedDB存储
- **云端备份**: 可选的Supabase云端同步
- **冲突处理**: 智能冲突检测与解决
- **实时同步**: 数据变更实时同步
