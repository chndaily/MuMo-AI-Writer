# 邮箱验证和密码重置功能说明

## 功能概述

木墨文坊系统现在支持邮箱验证和密码重置功能，以提高账户安全性：

1. **邮箱验证**：新用户注册后需要验证邮箱才能登录
2. **密码重置**：用户可以通过邮箱找回并重置密码

## 技术实现

### 后端实现

#### 1. 数据库字段更新
在用户文档中添加了以下字段：
- `isEmailVerified`: 布尔值，表示邮箱是否已验证
- `emailVerificationToken`: 邮箱验证token
- `emailVerificationExpires`: 邮箱验证过期时间
- `passwordResetToken`: 密码重置token
- `passwordResetExpires`: 密码重置过期时间

#### 2. API端点

##### 邮箱验证相关：
- `POST /api/auth/register`：注册时自动生成验证token并发送邮件
- `GET /api/auth/verify-email`：验证邮箱

##### 密码重置相关：
- `POST /api/auth/forgot-password`：请求密码重置
- `GET /api/auth/reset-password-validate`：验证重置token
- `POST /api/auth/reset-password`：重置密码

#### 3. 邮件服务
使用nodemailer库发送邮件，支持Gmail等SMTP服务。

### 前端实现

#### 1. 页面组件
- `EmailVerificationPage.tsx`：邮箱验证页面
- `ForgotPasswordPage.tsx`：忘记密码页面
- `ResetPasswordPage.tsx`：重置密码页面

#### 2. 路由配置
在App.tsx中添加了以下路由：
- `/verify-email`：邮箱验证页面
- `/forgot-password`：忘记密码页面
- `/reset-password`：重置密码页面

## 配置说明

### 环境变量配置
在`.env.server`文件中添加以下配置：

```env
# 邮件服务配置
EMAIL_SERVICE=gmail
EMAIL_USERNAME=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
EMAIL_FROM=your-email@gmail.com
```

### MongoDB索引建议
为提高查询性能，建议在MongoDB中为以下字段创建索引：
- `emailVerificationToken`
- `passwordResetToken`

## 安全考虑

1. **Token安全**：使用加密安全的随机token
2. **过期时间**：
   - 邮箱验证链接：24小时过期
   - 密码重置链接：1小时过期
3. **频率限制**：防止恶意请求发送大量邮件
4. **HTTPS**：确保所有验证链接通过HTTPS传输

## 使用流程

### 邮箱验证流程
1. 用户注册账户
2. 系统发送验证邮件到用户邮箱
3. 用户点击邮件中的验证链接
4. 系统验证token并激活账户
5. 用户可以正常登录

### 密码重置流程
1. 用户在登录页面点击"忘记密码"
2. 用户输入注册邮箱
3. 系统发送重置密码邮件
4. 用户点击邮件中的重置链接
5. 用户在重置页面输入新密码
6. 系统更新密码，用户可以使用新密码登录

## 常见问题

### 1. 邮件未收到
- 检查垃圾邮件文件夹
- 确认邮箱地址输入正确
- 等待几分钟后重试

### 2. 验证链接失效
- 验证链接24小时后过期
- 重新注册账户获取新的验证链接

### 3. 重置链接失效
- 重置链接1小时后过期
- 重新发起密码重置请求
