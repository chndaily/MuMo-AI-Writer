# 木墨文坊 (MuMo AI Writer) 使用说明

## 📋 文档概述

本文档提供了木墨文坊的详细使用说明，帮助用户快速上手并充分利用平台的各项功能。

## 🚀 快速开始

### 1. 系统访问
- 打开浏览器访问平台网址
- 注册账号或使用已有账号登录
- 选择会员等级（免费、基础、专业）

### 2. 创建小说项目
1. 点击"新建小说"按钮
2. 输入小说标题、类型和简介
3. 选择封面图片（可选）
4. 点击"创建"完成小说项目创建

### 3. 开始创作
- 在小说编辑器中直接输入内容
- 使用AI辅助功能生成内容
- 通过大纲规划章节结构
- 利用世界观设定工具构建故事背景

## 📝 核心功能使用指南

### 创作中心
创作中心是平台的核心功能模块，提供完整的小说创作环境：

#### 小说编辑器
- **实时预览**：编辑内容实时渲染为格式化文本
- **格式工具**：支持标题、加粗、斜体、列表等常用格式
- **快捷键**：支持常用编辑快捷键提高效率
- **版本管理**：自动保存历史版本，支持版本回滚

#### 章节管理
- **章节创建**：为小说添加章节，支持多级结构
- **章节排序**：通过拖拽调整章节顺序
- **章节状态**：标记章节为草稿、完成等状态
- **字数统计**：实时显示章节和全书字数

#### 大纲规划
- **结构化大纲**：支持多级大纲结构
- **AI辅助生成**：利用AI生成章节大纲建议
- **可视化展示**：以故事板形式展示大纲结构
- **同步更新**：大纲与章节内容保持同步

### AI工作台
AI工作台集成多种AI模型，提供智能写作辅助：

#### AI内容生成
- **模型选择**：支持OpenAI、Anthropic、Google、DeepSeek等多种AI模型
- **参数调节**：可调整温度、最大token等参数
- **上下文控制**：支持指定上下文长度
- **流式输出**：实时显示AI生成过程

#### 内容分析与优化
- **文本润色**：优化文本表达和语言流畅度
- **风格调整**：调整文本风格（正式、轻松、悬疑等）
- **语法检查**：检查并修正语法错误
- **重复检测**：检测内容重复并提供修改建议

#### 平行宇宙版本
- **多版本生成**：基于同一提示生成多个不同版本
- **版本对比**：并排对比不同版本的内容
- **混合编辑**：从不同版本中选取内容组合
- **版本保存**：保存有价值的版本供后续使用

### 世界观设定
世界观设定模块提供完整的六维世界观构建体系：

#### 角色设定
- **角色卡片**：创建详细的角色信息卡片
- **关系网络**：构建角色间的关系网络
- **成长轨迹**：记录角色在故事中的发展变化
- **可视化展示**：以图表形式展示角色关系

#### 地点设定
- **地点描述**：详细描述地点的外观、历史、文化等
- **地理关系**：构建地点间的地理和功能关系
- **重要性标记**：标记地点在故事中的重要程度
- **场景构建**：为关键场景提供详细的环境描述

#### 文化设定
- **文化背景**：构建故事世界的文化体系
- **社会结构**：描述社会阶层和组织结构
- **习俗传统**：记录重要的习俗和传统
- **宗教信仰**：构建宗教和信仰体系

#### 科技设定
- **技术水平**：定义故事世界的科技发展水平
- **科技应用**：描述科技在日常生活中的应用
- **科技限制**：设定科技发展的限制因素
- **科技影响**：分析科技对社会的影响

#### 魔法设定
- **魔法体系**：构建完整的魔法理论和规则
- **施法者**：描述不同类型的魔法使用者
- **魔法物品**：创建具有魔法属性的物品
- **魔法限制**：设定使用魔法的代价和限制

#### 历史设定
- **时间线**：构建详细的历史时间线
- **重大事件**：记录影响世界格局的重大事件
- **历史人物**：描述对历史产生重要影响的人物
- **文化遗产**：记录历史留下的文化遗产

### 数据同步
平台支持多种数据存储和同步机制：

#### 本地存储
- **浏览器存储**：自动保存到浏览器本地存储
- **离线访问**：支持离线状态下继续创作
- **数据安全**：本地数据加密存储
- **存储管理**：提供本地存储空间管理

#### 云端同步
- **MongoDB同步**：将数据同步到MongoDB数据库
- **Supabase同步**：可选的Supabase云端同步
- **冲突处理**：智能检测和处理数据冲突
- **同步状态**：实时显示同步状态和进度

### 用户管理
完善的用户管理系统：

#### 会员体系
- **三级会员**：免费、基础、专业三级会员体系
- **功能限制**：不同等级享受不同功能权限
- **AI次数**：每日AI生成次数限制
- **升级通道**：便捷的会员升级流程

#### 团队协作
- **团队创建**：创建和管理创作团队
- **成员管理**：添加和管理团队成员
- **权限分配**：为成员分配不同权限
- **协作编辑**：多人实时协作编辑

### 可视化工具
直观的数据可视化功能（专业会员专属）：

#### 关系图谱
- **角色关系图**：可视化展示角色间的关系网络
- **世界观图谱**：展示世界观各元素间的关系
- **交互探索**：支持缩放、拖拽等交互操作
- **详细信息**：点击节点查看详细信息

#### 情节结构图
- **故事线索**：可视化展示故事发展线索
- **章节关联**：展示章节间的关联关系
- **时间节点**：在时间轴上展示关键事件
- **悬念标记**：标记重要悬念和转折点

#### 创作进度分析
- **进度追踪**：可视化展示创作进度
- **字数统计**：统计各章节和全书字数
- **时间分析**：分析创作时间分布
- **效率评估**：评估创作效率和习惯

## ❓ 常见问题

### 技术问题
1. **无法登录**：检查网络连接和账户信息
2. **同步失败**：检查网络连接和数据库配置
3. **AI生成失败**：检查模型配置和API密钥
4. **数据丢失**：检查本地存储和云端同步状态

### 使用问题
1. **如何升级会员**：在账户设置中选择升级选项
2. **如何邀请团队成员**：在团队管理中添加成员邮箱
3. **如何导出小说**：在小说详情页点击导出按钮
4. **如何使用AI功能**：在AI工作台中选择相应功能
