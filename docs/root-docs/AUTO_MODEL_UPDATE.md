# AI模型自动更新功能说明

## 功能概述

本系统实现了AI模型的自动更新功能，能够定期从各个AI服务提供商获取最新的模型列表，并动态更新系统中的模型配置。这样可以确保系统始终使用最新的模型信息，而无需手动维护模型预设列表。

## 核心组件

### 1. MODEL_PRESETS (模型预设)
位于 [src/ai/modelPresets.ts](file:///E:/NovelSystem/taotao-writing-master/src/ai/modelPresets.ts)，包含系统预设的模型配置信息。

### 2. 动态模型缓存
系统会在运行时从AI服务提供商获取最新的模型列表，并将这些模型信息缓存到动态模型缓存中。

### 3. getAllModels() 函数
该函数返回所有模型（包括预设模型和动态获取的模型），确保系统能够访问到最新的模型信息。

## 工作原理

1. **定时刷新**：系统每24小时自动刷新一次所有配置的AI服务连接，获取最新的模型列表。

2. **动态更新**：当获取到新的模型列表时，系统会自动更新动态模型缓存。

3. **合并显示**：在需要显示模型信息时，系统会合并预设模型和动态获取的模型，确保显示最新的完整模型列表。

4. **自动同步**：获取到的模型信息会自动同步到数据库中，供所有用户使用。

## 使用场景

### 1. LLM配置页面
在LLM配置页面中，推荐模型会显示最新的模型信息。

### 2. AI测试页面
在AI测试页面中，用户可以选择动态获取的最新模型进行测试。

### 3. 系统默认模型
管理员设置的默认模型可以使用动态获取的最新模型。

## 优势

1. **实时性**：系统能够自动获取最新的模型信息，无需手动更新。
2. **完整性**：结合预设模型和动态模型，确保模型列表的完整性。
3. **透明性**：用户可以清楚地看到哪些模型是预设的，哪些是动态获取的。
4. **易维护**：减少手动维护模型列表的工作量。

## 注意事项

1. **网络依赖**：动态获取模型需要网络连接，如果网络不可用，系统会使用预设模型。
2. **API限制**：某些AI服务提供商可能对模型列表API有调用频率限制。
3. **缓存机制**：系统会缓存动态获取的模型信息，避免频繁调用API。

## 配置说明

- **刷新间隔**：默认每24小时刷新一次模型列表，可在代码中调整 `REFRESH_INTERVAL` 常量。
- **错误处理**：如果获取模型列表失败，系统会继续使用现有的模型信息，并在下次刷新时重试。

## 扩展性

该功能设计具有良好的扩展性，可以轻松添加新的AI服务提供商支持，只需实现相应的模型获取逻辑即可。
