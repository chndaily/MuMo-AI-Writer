# 关系可视化模块开发文档

## 模块概述

关系可视化模块是小说创作系统中的专业功能模块，旨在帮助创作者通过可视化图表更好地理解和管理复杂小说中的各种关系。该模块作为专业会员的核心功能，提供多种类型的可视化图表。

## 功能特性

### 1. 角色关系网络
- 展示小说中所有角色之间的关系网络
- 支持网络图和列表两种视图模式
- 可视化角色间的关系类型和强度

### 2. 世界设定网络
- 综合展示地点、文化、科技、魔法、历史等世界元素
- 按类型分组显示不同设定元素
- 支持元素间关系的可视化连接

### 3. 高级分析图表
- 情节线索图表
- 时间轴图表
- 综合分析图表

### 4. 数据管理
- 实时数据刷新
- 多格式导出功能
- 分享功能

## 技术架构

### 目录结构
```
visualization/
├── hooks/
│   └── useVisualizationData.ts    # 数据处理Hook
├── CharacterNetwork.tsx           # 角色关系网络组件
├── WorldSettingNetwork.tsx        # 世界设定网络组件
├── VisualizationSidebar.tsx       # 侧边栏导航组件
├── visualization.tsx             # 主页面组件
└── README.md                     # 本文档
```

### 核心服务
- `visualizationService.ts` - 提供数据处理和分析功能
- `useVisualizationData.ts` - React Hook，用于管理可视化数据状态

### 数据流
1. 从IndexedDB获取原始数据
2. 通过visualizationService处理分析数据
3. 生成适用于图表渲染的数据结构
4. 在组件中渲染可视化图表

## 组件说明

### VisualizationPage (主页面)
- 提供概览和详细视图两种模式
- 集成侧边栏导航
- 管理标签页切换

### VisualizationSidebar (侧边栏)
- 提供图表类型导航
- 支持快速切换不同可视化视图

### CharacterNetwork (角色网络)
- 专门展示角色关系的可视化组件
- 支持网络图和列表两种视图模式

### WorldSettingNetwork (世界设定网络)
- 综合展示各类世界设定元素
- 按类型分组显示不同元素

## 开发要点

### 数据处理
- 使用Zustand状态管理获取数据
- 通过Hook封装数据处理逻辑
- 实现错误处理和加载状态管理

### 可视化实现
- 使用原生DOM操作渲染简单图表
- 为未来集成专业图表库预留接口
- 支持响应式设计

### 路由配置
- 主路由: `/novels/:novelId/visualization`
- 子路由: 通过查询参数`view`指定具体图表类型
