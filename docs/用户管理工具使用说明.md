# 用户管理工具使用说明

## 概述

用户管理工具是一个命令行工具，用于管理木墨文坊系统中的用户账户。该工具可以直接操作MongoDB Atlas数据库，支持创建测试用户、查看用户列表、删除测试用户等功能。

## 工具文件位置

工具文件位于项目根目录下：
```
user-management.cjs
```

## 功能特性

1. **创建测试用户** - 批量创建预定义的测试用户账户
2. **创建单个用户** - 创建指定信息的单个用户账户
3. **列出所有用户** - 显示数据库中所有用户的详细信息
4. **删除测试用户** - 删除预定义的测试用户账户

## 使用方法

### 1. 查看帮助信息

```bash
node user-management.cjs
```

### 2. 创建默认测试用户

创建三个预定义的测试用户：
- 蜗牛丢了壳 (763337611@qq.com)
- 测试员1 (test1@example.com)
- 测试员2 (test2@example.com)

所有测试用户的默认密码为：`mumo123`

```bash
node user-management.cjs create-test
```

### 3. 创建单个用户

创建指定邮箱和姓名的用户：

```bash
node user-management.cjs create <邮箱> <姓名> [密码]
```

示例：
```bash
node user-management.cjs create newuser@example.com "新用户" mypassword
```

如果未指定密码，将使用默认密码：`mumo123`

### 4. 列出所有用户

显示数据库中所有用户的详细信息：

```bash
node user-management.cjs list
```

### 5. 删除测试用户

删除三个预定义的测试用户：

```bash
node user-management.cjs delete-test
```

## 用户数据结构

创建的用户包含以下完整信息：

### 基本信息
- `_id`: 用户唯一标识符
- `email`: 用户邮箱地址
- `name`: 用户显示名称
- `username`: 用户登录名
- `passwordHash`: 加密后的密码
- `isEmailVerified`: 邮箱验证状态（true/false）
- `createdAt`: 账户创建时间
- `updatedAt`: 账户更新时间

### 会员信息 (membershipInfo)
- `level`: 会员等级（FREE/BASIC/PROFESSIONAL）
- `expiryDate`: 会员过期时间
- `maxNovels`: 最大小说数量限制
- `aiGenerationLimit`: AI生成次数限制
- `aiGenerationUsed`: 已使用的AI生成次数
- `features`: 可用功能列表
- `teamEnabled`: 团队功能是否启用
- `maxTeamMembers`: 最大团队成员数
- `isAdmin`: 是否为管理员
- `username`: 会员系统中的用户名
- `email`: 会员系统中的邮箱

## 注意事项

1. **数据库连接**：工具会自动连接到配置的MongoDB Atlas数据库
2. **密码安全**：所有密码都使用bcrypt进行加密存储
3. **邮箱验证**：创建的测试用户默认邮箱已验证，可直接登录
4. **权限设置**：测试用户默认为免费会员权限
5. **管理员账户**：不会影响现有的管理员账户

## 常见问题

### 1. 工具执行时报错
确保已安装所有依赖：
```bash
npm install bcrypt
```

### 2. 数据库连接失败
检查MongoDB连接字符串是否正确配置在工具代码中。

### 3. 用户创建失败
确保提供的邮箱地址未被其他用户使用。
