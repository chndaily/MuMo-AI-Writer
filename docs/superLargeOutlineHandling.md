# 超长大纲处理指南

## 概述

当您的小说大纲超过30000字时，系统会自动启用超长大纲处理模式。该模式通过分层管理、摘要显示和智能优化等技术，确保您能够流畅地管理和使用超长大纲。

## 自动识别机制

系统会自动检测大纲的长度：
- 普通大纲：字数小于30000字
- 超长大纲：字数超过30000字

当检测到超长大纲时，系统会自动启用专门的处理机制。

## 处理特性

### 1. 分层管理
- 大纲按卷和章节进行层级化管理
- 每卷显示关键信息，避免信息过载
- 支持分页浏览完整的大纲内容

### 2. 摘要显示
- 在AI生成内容时，系统自动使用大纲摘要而非完整内容
- 摘要包含主要卷结构和关键章节信息
- 显著提高AI响应速度和系统性能

### 3. 智能优化
- AI服务针对超长大纲调整处理策略
- 增加内容长度限制，支持更复杂的结构
- 优化摘要生成算法，确保关键信息不丢失

## 使用建议

### 1. 结构规划
- 合理规划卷和章节结构，每卷控制在5-8个章节
- 保持核心主线清晰，支线适度展开
- 定期回顾和调整大纲结构

### 2. 内容管理
- 为重点章节添加详细内容描述
- 为每个章节编写摘要，便于系统处理
- 使用层级摘要快速了解整体结构

### 3. 导出备份
- 定期导出大纲作为备份
- 可选择完整导出或摘要导出
- 建议同时保存Markdown和纯文本格式

## 常见问题

### 1. 为什么我的大纲处理速度变慢了？
当大纲超过30000字时，系统会启用超长大纲模式，这会增加一些处理时间，但能确保更好的使用体验。

### 2. 如何查看完整的大纲内容？
可以使用大纲管理器的分页功能浏览完整的大纲内容。

### 3. AI生成内容时是否会使用完整的大纲？
不会，为了提高响应速度和避免信息过载，AI生成内容时会自动使用大纲摘要。

## 技术细节

### 判断标准
```typescript
// 超长大纲判断函数
export function isSuperLargeOutline(wordCount: number): boolean {
  return wordCount > 30000; // 超过30000字认为是超长大纲
}
```

### 处理流程
1. 系统检测大纲字数
2. 超过30000字时启用超长大纲模式
3. 自动生成层级摘要
4. AI交互时使用摘要而非完整内容
5. 提供分页浏览完整内容功能

通过以上机制，系统能够高效处理超长大纲，确保您获得流畅的创作体验。
