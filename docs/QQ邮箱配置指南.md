# QQ邮箱配置指南

## 为什么选择QQ邮箱

QQ邮箱作为国内主流的邮件服务提供商，具有以下优势：
- 国内访问速度快，稳定性好
- 配置简单，易于使用
- 安全性高，支持授权码验证
- 免费使用

## 配置步骤

### 1. 开启QQ邮箱的SMTP服务

1. 登录您的QQ邮箱（https://mail.qq.com）
2. 点击右上角的"设置"
3. 选择"账户"选项卡
4. 找到"POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务"
5. 开启"IMAP/SMTP服务"和"POP3/SMTP服务"
6. 如果是首次开启，系统会要求发送短信验证
7. 点击"生成授权码"，系统会发送短信到您的手机
8. 输入手机收到的短信验证码
9. 保存生成的授权码，这个就是您在环境变量中需要配置的密码

### 2. 配置环境变量

在项目根目录的 `.env.server` 文件中添加以下配置：

```env
# 邮件服务配置 (QQ邮箱)
EMAIL_SERVICE=QQ
EMAIL_USERNAME=your-qq-email@qq.com
EMAIL_PASSWORD=your-qq-authorization-code
EMAIL_FROM=your-qq-email@qq.com
```

配置说明：
- `EMAIL_SERVICE`: 邮件服务类型，设置为 `QQ`
- `EMAIL_USERNAME`: 您的完整QQ邮箱地址（例如：123456789@qq.com）
- `EMAIL_PASSWORD`: 第一步中生成的授权码（不是QQ密码）
- `EMAIL_FROM`: 发件人邮箱地址，通常与EMAIL_USERNAME相同

### 3. QQ邮箱SMTP参数

系统已内置QQ邮箱的SMTP配置参数：
- SMTP服务器：smtp.qq.com
- 端口：465
- 加密方式：SSL

### 4. 测试配置

配置完成后，您可以测试邮件发送功能：

1. 重启后端服务
2. 尝试注册一个新账户
3. 检查是否收到验证邮件

## 常见问题

### 1. 收不到邮件

- 检查垃圾邮件文件夹
- 确认QQ邮箱的SMTP服务已开启
- 确认授权码正确无误
- 检查防火墙设置

### 2. 授权码错误

- 确保使用的是授权码而不是QQ密码
- 如果忘记授权码，可以重新生成
- 授权码有时效性，建议定期更新

### 3. 邮件被识别为垃圾邮件

- 检查邮件内容是否包含敏感词汇
- 确保发件人地址与EMAIL_FROM一致
- 添加退订链接和公司信息

## 安全建议

1. **保护授权码**：
   - 不要将授权码提交到代码仓库
   - 定期更换授权码
   - 仅在必要时生成新的授权码

2. **邮件内容安全**：
   - 避免在邮件中包含敏感信息
   - 使用HTTPS链接
   - 添加过期时间限制

3. **频率限制**：
   - 避免短时间内发送大量邮件
   - 实施发送频率限制机制

## 其他支持的邮箱服务

除了QQ邮箱，系统还支持以下邮件服务：
- Gmail
- 163邮箱
- 126邮箱
- Outlook

如需使用其他邮箱服务，请参考相应服务商的SMTP配置参数。
