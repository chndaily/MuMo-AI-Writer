小说大纲提示词案例：

一、小说核心信息

【小说类型】：\_\_\_\_\_\_（如 "星际科幻""古风权谋""现代悬疑""东方奇幻"）；

【核心世界观】：\_\_\_\_\_\_（如 "星际科幻：人类殖民银河系，存在'异能者'与'机械族'对立；古风权谋：大靖王朝'士族'与'寒门'争夺权柄，皇室暗藏'秘术'"）；

【主线剧情】：\_\_\_\_\_\_（需包含 "主角核心目标 + 核心阻碍"，如 "主角为寻找失散的妹妹，揭露'机械族'操控星际联盟的阴谋；主角以寒门身份入宫，助七皇子夺嫡，同时揭开母亲当年'冤死'真相"）；

【目标总字数】：\_\_\_\_\_\_（如 "15 万字""30 万字"），根据字数合理分配卷数（10-20 万字建议 3-4 卷，20-30 万字建议 5-6 卷）与每卷章节数（每卷 6-8 章）及单章预估字数（例：15 万字 3 卷 24 章，单章约 6250 字；30 万字 5 卷 40 章，单章约 750 字）。

【作品主题】：\_\_\_\_\_\_（如"正义与信任的辩证关系""个体成长与集体责任的平衡""科技发展与人性保持的冲突"）

【核心寓意】：\_\_\_\_\_\_（如"真正的勇气不是无所畏惧，而是在恐惧中依然前行""团结的力量可以战胜一切困难"）

二、卷的格式与内容要求（用 "##" 标记，定阶段框架）

格式：## 第 X 卷：\[卷名，需体现本卷核心主题，带风格感]（例："## 第 2 卷：咸阳棋局・暗流""## 第 3 卷：星际迷雾・卧底"）；]

内容：（每卷必含 4 点，精简总结，不冗余）

【本卷核心任务】：明确主角的阶段目标，分 "核心目标" 与 "次要目标"（例："核心目标：获取反派据点的密信；次要目标：修复与配角 A 的信任关系"），需贴合主线方向；

【本卷主要冲突】：标注冲突类型（外部 / 内部），说明 "冲突双方 + 冲突焦点"（例："外部冲突：主角 vs 反派的'密信争夺'；内部冲突：团队对'是否信任新卧底'的分歧"）；

【本卷氛围与意义】：定义卷内整体调性，说明阶段作用（例："氛围：诡谲紧张；意义：铺垫期，完善反派组织架构，埋下'卧底身份存疑'的关键伏笔"）；

【本卷人物变化】：主角 / 1-2 个关键配角的阶段成长，需关联本卷冲突（例："主角从'盲目信任'到'谨慎判断'（因被卧底误导）；配角 A 从'对立'到'中立协助'（因主角救其家人）"）。

三、章节的格式与内容要求（用 "###" 标记，填细节血肉）

格式：### 第 X 章：\[章节名，需概括本章核心事件，含 "场景 + 核心事件"，带画面感]（例："第 5 章：雨夜茶馆・密信惊魂""第 7 章：星际驿站・身份暴露"）]；

内容：（每章必含 3 大模块，覆盖情节、细节与创作指导，200-300 字）

模块 1：基础信息（铺垫前提，100-150 字）

【时空与人物】：明确 "具体时间（如'暮春亥时''星际纪元 302 年'）+ 核心场景（如'城南忘忧茶馆二楼包间''阿尔法空间站维修舱'）+ 关键人物（标注关系，如'主角陈默 + 卧底阿杰 + 反派老鬼'）"；【章节功能】：标注本章在卷内的作用（如 "线索转折型""冲突爆发型""人物成长型"），例："线索转折型：主角与卧底接头获密信，遭遇反派追踪，密信被撕成两半"。

模块 2：剧情关键节点（核心血肉）

1、必选要点（每章需完整覆盖，共 6 点）

①类型元素

定义与要求：嵌入小说核心类型（如悬疑、科幻、古风等）的具体细节，需融入情节逻辑，不可孤立存在。示例（现代悬疑题材）：悬疑元素体现在茶馆包间墙壁的 "暗格"（用于藏匿密信）、反派老鬼手上的 "黑色皮手套"（指尖沾有主角头发，为后续追踪埋下线索）；现实元素则通过茶馆老板的 "蜀地方言" 呈现，暗示反派核心据点位于蜀地，为后续地域线索铺垫。

②冲突

定义与要求：明确本章核心矛盾（外部冲突 / 内部冲突），需包含 "冲突双方 + 冲突焦点 + 冲突升级触发点"。示例（现代悬疑题材）：外部冲突为主角陈默 vs 反派老鬼，冲突焦点是争夺暗格内的半张机密信件；冲突升级点出现在老鬼撞开包间门时 —— 卧底阿杰突然将密信塞进陈默口袋，自己侧身挡在门口，形成 "以人拦人" 的对峙局面，让冲突从 "潜在" 转为 "直接对抗"。

③伏笔（含回收）

定义与要求：需包含两部分，一是新增伏笔（明确 "伏笔载体（物品 / 动作 / 对话）+ 核心信息（关联后续剧情的关键）"），二是回收伏笔（若有，需标注 "前序伏笔所在章节 + 本章回收逻辑"）。示例（现代悬疑题材）：新增伏笔为阿杰挡门时，领口滑落的 "半截蛇形金属吊坠"（载体），吊坠纹路与前卷第 3 章 "反派组织标记" 完全一致（核心信息，暗示阿杰与反派的深层关联）；回收伏笔对应前卷第 2 章 "主角捡到的陌生手机号"（前序章节），本章阿杰用该手机号给陈默发 "茶馆见" 的暗号，证实该手机号是卧底专用联络号（回收逻辑）。

④高潮

定义与要求：本章情节转折点 / 情绪峰值，需包含 "高潮发生场景 + 核心动作 / 关键对话 + 张力来源（打破预期 / 危机升级）"。示例（现代悬疑题材）：高潮发生在茶馆二楼包间门口；核心动作与对话是阿杰抓起桌上滚烫的茶水，朝老鬼脸上泼去，同时喊 "陈默快跑！别管我！"；张力来源在于阿杰的 "牺牲式掩护" 打破了主角 "卧底不可信" 的预判，且茶水泼洒引发老鬼暴怒，冲突从 "争夺密信" 转向 "生死对抗"，情绪张力拉满。

⑤影响

定义与要求：分两类说明，一是情节影响（关联后续章节的具体剧情走向），二是角色影响（推动主角 / 关键配角的心态变化或成长）。示例（现代悬疑题材）：情节影响为密信被老鬼撕走一半，仅剩半张带编码的残页，后续第 6 章需 "主角寻找阿杰补全另一半密信"；角色影响体现在主角陈默身上，他目睹阿杰冒险掩护后，从 "对所有合作者保持警惕" 的封闭心态，转变为 "愿意相信值得托付的人"，为后续接纳新伙伴（如技术专家）铺垫。

⑥深度

定义与要求：需包含两部分，一是主题关联（链接小说核心主题，如 "正义与信任""个体与集体"），二是世界观补充（展现小说世界的规则 / 背景细节，避免情节浅层化）。示例（现代悬疑题材）：主题关联上，通过阿杰 "明知暴露会被灭口，仍选择掩护主角带信离开" 的行为，深化 "正义不是独善其身，而是敢于为他人承担风险" 的核心主题；世界观补充上，从老鬼 "必须带回完整密信，否则受罚" 的台词，侧面体现反派组织 "层级森严、容错率极低" 的管理规则，丰富反派体系设定。

2、可选要点（按本章情节侧重选 2-3 个，增强个性化）

①角色向・角色弧光

定义与要求：展现关键配角（或主角）在本章的微型成长轨迹，需关联本章冲突或高潮事件，避免脱离情节的 "突兀成长"。示例（现代悬疑题材）：卧底阿杰的弧光的完整呈现 —— 从开篇 "说话结巴、不敢与主角对视" 的胆小状态，到高潮 "主动泼茶挡敌、大声喊话" 的勇敢转变，完成 "懦弱→担当" 的微型成长，让配角形象更立体。

②情节向・反转

定义与要求：出现超出预期的情节转折，需符合小说世界观逻辑且不突兀，最好能关联前文伏笔（或已展现的规则），避免 "强行反转"。示例（现代悬疑题材）：反转内容为老鬼追上巷口的陈默时，突然接到电话，电话里传来 "停止行动，高层要留活口" 的指令，老鬼虽愤怒但被迫撤退；合理性上，该反转呼应前文 "反派组织层级森严" 的设定，同时暗示反派高层对主角有 "特殊用途"，为后续 "主角被抓却未被灭口" 的剧情铺垫。

③氛围 / 意象向・象征意象

定义与要求：提炼本章具有隐喻意义的物品、场景或动作，需关联剧情主题或角色状态，让 "意象" 成为 "情节的延伸"，而非单纯的装饰。示例（现代悬疑题材）：本章全程伴随的 "暴雨"（场景意象）具有多重隐喻 —— 暴雨模糊视线，对应 "真相模糊"（密信仅存半张、阿杰身份半露半藏）；雨水打湿衣服，对应 "角色陷入困境"（主角带残信逃亡、阿杰被老鬼控制），让氛围与情节深度绑定。

④世界观向・设定展示

定义与要求：通过情节自然呈现小说世界观的细节（如规则、技术、组织架构等），不刻意用 "旁白说明"，让读者通过角色行为或事件感知世界逻辑。示例（现代悬疑题材）：反派老鬼追捕时，从口袋掏出 "微型追踪器"，追踪器屏幕显示 "目标信号（陈默）微弱"—— 该情节自然展现反派已掌握 "基于人体气味的追踪技术"，既解释了老鬼能快速找到茶馆的原因，也为后续 "主角如何通过掩盖气味反追踪" 提供了世界观依据。

模块 3：创作适配（指导正文，落地可用）

【落地建议】：针对 "剧情关键节点" 给写作细节，例："写阿杰的蛇形吊坠时，可加'吊坠晃到主角眼前，主角瞥了一眼没多想'，避免刻意，后续揭晓更自然；写高潮时，用'茶水泼在老鬼手上的滋滋声'强化听觉张力"；

【主线支线】：明确本章主线（如 "夺密信"）与支线（如 "阿杰的卧底背景"）的关系，例："支线'阿杰吊坠'需服务主线'找反派据点'，后续 7 章通过吊坠线索，引出'卧底分外围 / 核心'的主线信息"；

【字数分配】：标注本章预估字数（如 "2500-3000 字"）及内容占比，例："场景描写 25%（雨景 + 茶馆）、人物互动 40%（对话 + 动作）、细节铺垫 35%（伏笔 + 类型元素）"。

【节奏控制】：标注本章节奏快慢（如"快节奏：连续动作场面""慢节奏：心理描写为主"）及张弛结合安排（如"高潮后安排一段温馨日常作为缓冲"）

【章节悬念】：本章结尾设置的悬念，吸引读者继续阅读（如"主角发现密信上竟然是自己的名字""反派突然出现在主角身后"）

【后续钩子】：为下一章埋下的伏笔（如"神秘人留下的地图碎片""主角身上出现的奇异印记"）

四、大纲逻辑与衔接要求（确保连贯，不脱节）

卷与卷衔接：后一卷开篇需呼应前一卷收尾，且后一卷核心任务需直接承接前一卷未完成的目标（例：前卷结尾 "主角拿到半张密信"，后卷开篇 "主角制定'找阿杰补全密信'的计划"）；

章与章衔接：下一章需承接上一章的 "伏笔" 或 "未解决冲突"（例：上一章 "主角手臂被老鬼划伤"，下一章 "伤口感染，需找医生治疗，引出新配角'民间医士'"）；

主线聚焦：所有章节的 "剧情关键节点" 需服务卷核心任务，卷核心任务需服务主线剧情，避免无关支线（如 "主角夺密信" 主线，不新增 "主角帮茶馆老板寻子" 的独立支线）。

【支线管理】：明确支线与主线的交织方式（如"支线A在第3章提供关键道具""支线B在第5章引发新的冲突"）

【线索整合】：说明如何将多条线索汇聚到主线（如"各条支线的线索最终都指向反派的真实身份"）

五、整体约束（避免 bug，保质量）

世界观适配：所有 "类型元素""冲突""伏笔" 需贴合核心世界观（例：古风权谋不可出现 "星际战舰"，星际科幻不可出现 "古代玄学咒语"）；

角色成长连贯：章节 "角色影响" 需逐步叠加，形成完整弧光（例：主角从 "警惕"→"信任"→"学会权衡"，不可突然反转）；

创造性与落地平衡：鼓励 "类型元素融合"（如 "科幻 + 悬疑"：机械族的 "记忆读取设备" 有 "仅读 1 小时记忆" 的限制，制造悬疑），但需确保细节可落地（设备需有 "能量消耗" 限制，避免万能）。

【读者共鸣点】：设计能引起读者共鸣的情节或角色特质（如"主角面对选择时的纠结""配角的牺牲精神"）

【情感高潮】：规划能引发读者强烈情感反应的情节点（如"英雄救美""生死离别"）

【系列伏笔】：为后续作品埋下的长远伏笔（如"神秘组织的真实目的""未解之谜的深层真相"）

【扩展空间】：说明本作品为系列留下的发展空间（如"世界观的其他地域""其他角色的独立故事"）

角色提示词案例：

请严格围绕已有的小说大纲（含大纲内提及的人物、情节、核心冲突），优先补充大纲已有人物的细节设定，再按需扩展新增角色，确保所有角色与大纲情节强绑定、无逻辑冲突。

角色设定生成总要求：

1\. 第一步：补充 "大纲已有人物" 的细节（优先完成）

对 "大纲已有人物"，按生成要求补充完整设定，不新增与大纲冲突的信息，确保所有角色与大纲情节强绑定、无逻辑冲突。

2\. 第二步：扩展 "大纲需补充的功能性角色"（按需生成，补剧情缺口）

根据大纲情节缺口（如 "主角缺'技术支持'"反派缺'执行层手下'"剧情缺'递线索的路人'"），按以下通用分类新增角色，所有新增角色需在描述中明确 "出场阶段 + 核心功能 + 与已有角色的关联"：

（1）主角团互补角色（1-2 人，弥补主角短板，如大纲中已有人物无需增加）

功能定位：填补主角在 "能力 / 性格 / 资源" 上的缺口（如主角 "擅长战斗但不懂解谜"，需 "理智型解谜伙伴"；主角 "冲动冒进"，需 "冷静型战术规划者"）。

（2）反派团分支角色（3-5 人，承接反派任务）

功能定位：分担主反派的 "执行 / 迷惑" 任务（如主反派 "幕后策划"，需 "前线动手的打手"；主反派 "伪装正派"，需 "暗中传递假消息的卧底"）。

（3）辅助型配角（5-8 人，长期提供支持）

功能定位：覆盖 "引路 / 治疗 / 信息 / 资源" 等长期需求（如 "仙门长老→提供修仙知识""城市医生→治疗主角团队伤势""末世商人→提供稀缺物资"）。

（4）功能性配角（3-5 人，单一任务后退场）

功能定位：完成 "递线索 / 临时救场 / 触发事件" 等单一任务（如 "茶馆小二→告诉主角'反派去了城外破庙'"路过的猎人→临时救下被野兽围攻的主角'"）。

3\. 整体约束（通用适配，避免设定混乱）

世界观契合：所有角色的能力、背景、行为逻辑，需贴合 "作品核心世界观"。

无重复冗余：避免角色核心功能重复（如已有 "技术担当"，新增角色需定位 "战术 / 治疗" 等其他功能）；避免 "工具人" 角色过多（功能性配角控制在 1-2 人内）。

服务主线：所有角色的设定（含个人恩怨、成长线）需指向 "主线剧情"，不添加无关支线（如新增角色的 "家族恩怨"，需关联 "主角寻物 / 反派阴谋" 等核心剧情）。

格式统一：所有角色（含已有人物、新增角色）均按 "【基础信息】【外貌特征】【性格特质】【背景补充】【能力设定】【关联逻辑】【细节补充】" 模块呈现，便于整理与后续创作。

【情感线索】：明确角色的情感发展轨迹（如"从孤独封闭到学会信任""从复仇执念到宽恕和解"）

（2）人物关联历史（1 个，补充主角 / 反派身世）功能定位：填补 "主角 / 反派身世" 的空白（如 "主角家族的过往""反派的历史执念"），需明确 "历史伏笔""与当前剧情的关联"（如 "主角祖父曾是'守护神器的卫士'，因'背叛'被污蔑，对应大纲'主角为祖父洗冤 + 继承使命'剧情"）。

（3）道具 / 地点关联历史（1-2 个，支撑关键剧情）功能定位：解释 "核心道具 / 地点" 的起源（如 "神器的历史用途""反派据点的过往"），需明确 "历史功能""当前价值"（如 "反派据点曾是'古王朝监狱'，地下有'压制能力的禁制'，对应大纲'主角利用禁制削弱反派战力'剧情"）。

（4）禁忌 / 秘闻历史（1 个，推动冲突升级）功能定位：揭露 "世界观隐藏危机"（如 "被掩盖的'末日预言'"禁忌技术的灾难史"），需明确 "历史真相""与反派阴谋的关联"（如 "反派试图复活'古王朝禁忌生物'，而该生物曾导致'半个大陆毁灭'，对应大纲'主角阻止反派复活生物'剧情"）。

整体约束（通用适配，避免设定混乱）

世界观契合：所有历史的事件背景、发展逻辑，需贴合 "作品核心世界观"（如 "封建王朝" 不可设定 "星际战争历史"，"末世题材" 不可设定 "和平盛世的奢华历史"）；

逻辑连贯：历史事件的 "起因→经过→结果→影响" 需闭环，不可矛盾（如 "古王朝因'神器内战'覆灭，后续剧情不可出现'神器从未引发冲突'的设定"）；

无重复冗余：避免历史事件重复（如已有 "古王朝覆灭秘闻"，不可再新增 "另一个古王朝" 也因相同原因覆灭）；

服务主线：所有历史的设定（含秘闻、伏笔、影响）需指向 "主线剧情"（如 "禁忌生物的灾难史，需关联'主角阻止反派复活生物'核心剧情"）；

格式统一：所有历史（含已有历史、新增历史）均按 "【名称】【标签】【描述】【时间线】【重要事件】【历史人物】【历史后果】【细节补充】" 模块呈现，便于整理与后续创作。
